# エンスク授業ノート | 桜紅さん

授業・セオリー図鑑・緑のフクロウの相棒を使って復習する、スマホ優先の授業ノートです。

- 公開画面: https://tenten-ensuku.github.io/sakurakou-lesson-review/
- このリポジトリは桜紅さん専用です。瀬利さりなさん版とは別の教材・DBです。
- 表示版と内部版は `app/lib/lesson.mjs` の `APP_VERSION`（ver17）に統一しています。

## 機能

- 日付順の授業一覧、途中再開、動画・参考資料、カードの反転と解き直し。
- 三種の神器と照合した14の知識と28の確認問題（四択・タップ式穴埋め）。図鑑は未収集でも読めます。
- 「わかった」は収集のみ。確認問題の初正解・翌日以降・初正解の7日後以降で段階的に星を獲得します（日本時間）。休んでも星は減りません。
- 星3個で眼鏡、10個でマフラー、20個で帽子、30個で部屋。解放した装いは付け替え可能。
- 公開教材の編集、授業・カードの追加・削除・復元、問題一覧のドラッグ並び替え、画像・URLの入力。
- 個人記録は匿名のオンライン保存と端末内保存を併用。秘密の引継ぎコードで復元、別の読み取り専用リンクで講師へ共有・失効。

星はアプリ内の復習履歴です。理解度を保証する資格ではありません。

## 開発と検証

Node.js 22.13以降（検証環境は24.14）、Windowsでは `npm.cmd` を利用します。

```sh
npm ci
npm run dev
npm run typecheck
npm run lint
npm test
npm run build:pages
```

`npm run build` は既存Sitesバックエンド用のvinextビルド、`build:pages` はGitHub Pages用の静的出力 `out/` です。後者は既存の公開APIを参照します。ローカルで既存の公開教材を試す場合は、開発サーバーを一度起動してから `node scripts/seed-local.mjs` を実行します。ローカルD1だけを書き換え、本番には書き込みません。

## 保存と公開

教材は既存D1/R2を維持し、図鑑・確認問題・表示順・個人イベントのテーブルだけを追加します。既存IDや教材を一括移行・上書きしません。図鑑の初期データは初回のみ登録し、以後の編集を上書きしません。

バックエンドの対象は `.openai/hosting.json` の既存project_idです。バックエンド更新後、GitHubの `main` にソース、`gh-pages` に検証済みの `out/` を公開します。バックエンド更新なしでPagesだけを公開しないでください。

引継ぎコードやサービスの認証情報はコミットしないでください。保護範囲は `docs/personal-records.md`、教材照合記録は `docs/canonical-review.md` を参照してください。
