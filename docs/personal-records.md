# 個人記録と共有の設計

`/api/catalog` と既存の教材APIは公開編集用です。個人記録API `/api/learning/*` は別の認証境界です。教材を編集できても、他人の学習記録を読み書きする権限にはなりません。

初回起動時に暗号学的乱数で256bitの秘密コードを作り、HTTPSのAuthorizationヘッダーで送ります。サーバーはSHA-256のハッシュだけを保存し、秘密コード自体をDBに保存しません。コードはパスワードと同等なので本人が保管してください。紛失し、端末側の記録も消えた場合には本人確認による再発行はできません。

講師リンクは別の256bitトークンです。URLフラグメントから読み込み、専用GET APIにだけ使います。対象は知識の到達段階、解き直し対象、最終復習日と集計。回答イベント・引継ぎコード・途中セッションは返しません。本人が発行済みリンクを一括失効できます。リンクを知る人は閲覧できるため、SNS等には公開しないでください。

## オフラインと整合性

- `ensuku-notebook-learner-v1` にコード、受信イベント、未送信キューを保存。
- 学習結果を先に画面へ反映し、通信後にサーバー採点イベントで照合。
- 解答は `attempt:セッションID:問題ID` を一意キーにし、再送・連打でも一度だけ保存。
- 進捗はイベントから再計算。星は日本時間の日単位で判定し、同日では昇格しない。
- 問題の版が変わった未送信解答はサーバーが拒否し、解き直すよう通知。
- 接続復帰と15秒間隔で未送信を同期。ブラウザ保存不可ならメモリで続け、警告。
- 旧端末の解き直しIDは一度だけ取り込む。過去の自己申告から正解履歴や星を作らない。
- 引継ぎ前の端末記録はローカル退避。同じコードで復元した際には未送信も再結合。

アカウントなしの学習補助です。端末日時の変更や公開教材の正解閲覧による得点操作を防ぐ資格試験システムではありません。ランキング・課金は設けません。

教材の論理削除で学習履歴と報酬は失われません。表示番号は位置から計算し、IDは変えません。D1変更は `0005_learning_encyclopedia.sql` による追加のみです。バックアップ・保管期間の運用を変える際は、匿名コードで管理される個人データも対象に含めてください。
