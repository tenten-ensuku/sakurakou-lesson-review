# ver23: 教材優先表示と授業の入口整理

- 8/18の既存「ねじまき鳥授業要約+30問」を、安定した授業IDと資料IDで優先表示する。設定は `content/featured-materials.json`。
- 資料一覧と編集画面は共通の `orderMaterials` を使用。表示優先度のみ変更し、共有DBの既存順序、教材名、URL、ID、削除状態、個人学習記録は変更しない。資料が削除された場合も復活させない。
- 指定資料は授業一覧の問題開始ボタンより上にも直接リンクを表示。アプリ内6問と外部教材30問を合算しない。
- 授業タイトルは非クリックの見出しに変更。問題と資料の入口を常時表示し、アイコンだけの動画リンクは文字付きに変更。
- 復習形式、途中再開、解き直し、問題一覧は授業ごとの復習画面へ集約。検索欄へ移動するだけのボタンと、下部タブと重複する解き直しボタンを授業一覧から除く。
- 既存のフラッシュカード反転・四択採点・教材編集・途中状態の保存方式は維持。

## 確認

- 8/18の一覧から教材へ直接アクセスでき、資料ダイアログでも同じ教材が先頭。
- 8/18の6問を開始、正答・解説表示、解き直し登録、途中保存、再開入口を確認（ローカル環境のみで学習操作）。
- スマホ390px・320pxで横はみ出しなし。狭い画面は入口ボタンを縦並びにし、件数は独立した行に表示。
- 自動テストで、データ非破壊、削除資料を復活させない、動的な件数、資料のない授業に資料ボタンを出さないことを確認。
